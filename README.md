# Expense-Tracker-Project
Managing daily expenses manually can be difficult and time-consuming. Many users are unable to track where their money is being spent, which leads to poor financial planning.  The Expense Tracker Application is designed to solve this problem by providing a digital platform where users can record and analyze their expenses in an organized way.
